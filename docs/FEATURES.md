# MapleStory Character Toolkit — feature reference

Character profiles, equipment notes, and activity records form the core of MapleStory Character Toolkit. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Character profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Equipment notes | Equipment categories and the associated selection or configuration options. |
| Activity records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
